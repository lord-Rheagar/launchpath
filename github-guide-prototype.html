03 / Set up

Get to your first connection

Four steps for the custom OAuth app route.

1

Get your redirect URI

Start creating a custom auth configuration for GitHub in Composio. Copy the redirect URI shown in the relevant setup instructions.

Open custom auth instructions ↗

Done when: You have the redirect URI ready to enter in GitHub.

2

Register an OAuth app with GitHub

In GitHub, open Settings → Developer settings → OAuth apps → New OAuth App. Enter your app information and authorization callback URL.

Open GitHub’s registration guide ↗

Done when: GitHub shows your registered OAuth app.

3

Complete your auth configuration

Follow the Composio dashboard instructions to enter the required credentials and save the configuration. Keep credentials in Composio, not in this guide.

View auth configuration instructions ↗

Done when: Your custom auth configuration is created.

4

Test your connection

Start a GitHub connection through your configured route. Sign in and review the requested permissions. Then try a small action relevant to your agent.

View connection instructions ↗

Done when: Your account is connected and the test action succeeds. The exact test still needs verification.

04 / Launch

Getting ready for customers

Your own test connection is a milestone. Customer access can introduce additional requirements.

Organization access may need approval

A GitHub organization can restrict OAuth app access. An organization owner may need to approve your app before it can access that organization’s resources.

Understand organization restrictions ↗
05 / Get unstuck

Common blockers

Know who can help and what to do next.

I can connect, but can’t access organization repositories

Possible reason: The organization restricts OAuth app access.

Who can help: A GitHub organization owner.

Next: Ask an owner to review the app and requested permissions. Share the app’s purpose and the access it needs.

How to request approval ↗
I’m seeing a callback or redirect error

Next: Compare the callback URL registered in GitHub with the redirect URI required by the selected Composio auth configuration.

Who can help: The developer or person managing the OAuth app.

This troubleshooting step has not been tested in this prototype.
